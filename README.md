# Frontend Mentor Project - Landing Page

This is a solution to a [Frontend Mentor](https://www.frontendmentor.io) challenge.  
The goal of this project was to practice **HTML, CSS, and responsive layouts** with a simple landing page design.  

---

## 🚀 Features
- Clean and responsive **landing page layout**  
- Mobile-first design approach  
- Simple **HTML + CSS structure**  
- Testimonials carousel implemented using A11YSlider
  for accessible sliding functionality.

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3 (Flexbox, Responsive Layouts)**
- **Vanilla JavaScript** (minimal usage)

---
